##Инструкция по проверке и запуску 

##Системные требования
ОС Linux с поддержкой KVM/libvirt
Установленные пакеты 'qemu-kvm', 'libvirt-daemon-system', 'virtinst', 'cloud-image-utils', 'make', 'git'.
#Пошаговая проверка
1. Клонирование репозитория
git clone [https://github.com/in-cogni/cloud-maker.git](https://github.com/in-cogni/cloud-maker.git)
cd cloud-maker

2. Запуск развертывание (создание моста, проверкатквот, генерация seed.iso и запуск ВМ): 
sudo make run
В результате скрипт проверит квоты памяти, подготовит образ диска и сгенерирует cloud-init диск. В терминале запустится установка через virt-install.
В самом конце выполнения команд автоматически вызовется virsh list и появится созданная виртуальная машина в статусе runnung/

3. Очистка системы
sudo make clean
В результате виртуальная машина будет корректно остановлена и удалена из гипервизора. Все временные файлы дисков (.qcow2) и 
ISO-образы будут полностью удалены с хоста.
